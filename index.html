Two programs, two specialty applications

Illustrator is where you draw. InDesign is where you arrange. Beginners learn them side by side, so a logo made in one can land on a page built in the other.

Adobe Illustrator

For image creation, branding, Typographic graphic design work. Draw shapes, icons, and logos that stay sharp at any size.

  • Build artwork from basic shapes and the Pen tool
  • Choose and organize color with swatches
  • Set type and turn it into artwork
  • Save and export for screen and print

Adobe InDesign

Lay out text and images across one page or many.

  • Set up pages, margins, and columns
  • Flow text through frames and place images
  • Save formatting as styles so pages stay consistent
  • Export a PDF ready to share or print

No design background needed. If you can use a word processor, you can start here.

The tools you’ll use most

Pick a program to see the handful of tools beginners reach for in every session.

Selection V

Move, resize, and rotate whole objects.

Direct Selection A

Edit individual anchor points and handles to reshape a path.

Pen P

Draw precise straight lines and smooth curves.

Shape tools M L

Draw rectangles and ellipses, the building blocks of most logos.

Shape Builder Shift+M

Merge or cut away overlapping shapes by dragging across them.

Type T

Add text, choose fonts, and turn letters into outlines for artwork.

Eyedropper I

Copy color and style from one object to another.

Artboards Shift+O

Keep pages of different sizes together in one file.

Selection V

Select, move, and resize frames and the objects inside them.

Type T

Draw a text frame and start writing, or place text from a document.

Rectangle Frame F

Create a placeholder frame for an image, then fill it later.

Gap U

Adjust the space between objects so columns and rows stay even.

Pages panel F12

Add, move, and delete pages, and apply a parent page.

Parent pages

Set page numbers, headers, and margins once and repeat them everywhere.

Paragraph Styles

Save text formatting and apply it in one click for consistent pages.

Export Ctrl/Cmd+E

Save a PDF for screens or for a print shop.

How the cohort runs

Four hands-on sessions. Each one ends with something you made.

  1. 1

    Meet Creative Cloud

    Tour the workspace, set up your files, and get the shared resource guide. Bring a few examples of design you admire for a short portfolio introduction.

  2. 2

    Draw in Illustrator

    Build a simple logo from shapes, apply a color palette, and set a name in type.

  3. 3

    Lay out in InDesign

    Set up a multi-page document, flow text into frames, and save paragraph styles.

  4. 4

    Make your word page

    Combine both programs into a magazine-style page made of words about you, then share it with the group.

Keep practicing between sessions. Adobe publishes free step-by-step tutorials for each program.

Print media terms

Margin
The space between the page edge and the main content. Keep important text and images inside it.
Bleed
Artwork that extends beyond the trim edge so color reaches the cut edge. 0.125 in (3 mm) is common; check your printer’s specifications.
Gutter
The space between columns, or the inner margin where facing pages meet at the binding.

Design keywords

Alignment
How text and objects line up to create order.
Contrast
Differences in size, color, or weight that help elements stand apart.
Hierarchy
The visual order that guides readers to what matters first.
White space
Open space around content that helps a layout feel clear and balanced.
Typography
The choice and arrangement of type to make text readable and expressive.
